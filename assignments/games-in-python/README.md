# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. Students will practice creating a simple interactive game that tracks guesses, reveals letters, and ends when the player wins or runs out of attempts.

## 📝 Tasks

### 🛠️ Build the Game Logic

#### Description
Create a word-guessing game where the player tries to guess letters in a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list of words
- Display the hidden word as underscores such as `_ _ _ _ _`
- Accept letter guesses from the player using `input()`
- Reveal correctly guessed letters in the correct positions
- Track the number of incorrect guesses remaining
- End the game when the word is fully guessed or the player runs out of attempts
- Display a clear win or lose message at the end of the game

### 🛠️ Improve the User Experience

#### Description
Add a few polished game features to make the program more interactive and easier to use.

#### Requirements
Completed program should:

- Prevent duplicate guesses from being counted multiple times
- Show the letters already guessed during the game
- Tell the player whether their guess was correct or incorrect
- Include a simple message when the player wins or loses
- Keep the game loop running until the player decides to stop or the game ends
